# Aurora World

可以在瀏覽器裡逛的 3D 世界：Grand Aurora 大飯店、星光童話王國、Aurora Galleria 購物中心、翠谷自然公園（山林、溪流、瀑布和豪華露營區）。

- 完整版（四個世界）：`index.html`
- 飯店版（只有飯店和奧蘿拉熊）：`hotel.html`

素材：建築與場景以 Blender 程式產生；角色米雅、米露與奧蘿拉熊以 Tripo 產生；機器人替身 RobotExpressive（Tomás Laulhé，CC0）；人物替身 Quaternius Ultimate Animated Character Pack（CC0）；引擎 three.js、three-mesh-bvh（MIT，授權檔在 `park/viewer/lib/`）。
